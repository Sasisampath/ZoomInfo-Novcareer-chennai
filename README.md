# ZoomInfo Chennai jobs – November 2026

A minimal, mobile-first static directory curated by @productwithsasi, inspired by the [November 12 fintech Chennai hiring](https://github.com/Sasisampath/November-12-fintechchennaihiring) design.

- Seven distinct role cards for Chennai.
- Six links open an individual ZoomInfo careers posting supplied by the curator.
- One link (GTM Integration Specialist II) opens its matching LinkedIn job listing until the individual ZoomInfo employer URL is confirmed.
- Search by title or department.
- No founders, company background, or revenue section.
- No framework, install or build step.

**Run locally**

```sh
python3 -m http.server 5600
```

Open http://localhost:5600.

**Deploy on Vercel**

Import the GitHub repository as a new static site. Select Other framework, root directory `.`, no build or install command.
