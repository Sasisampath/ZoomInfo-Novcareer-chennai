# ZoomInfo Chennai Job Openings — November 2026

A lightweight, mobile-first job directory curated by @productwithsasi. Design reference: [November 12 Chennai fintech hiring](https://github.com/Sasisampath/November-12-fintechchennaihiring).

- Seven unique Chennai job cards
- Six individual ZoomInfo careers job URLs supplied by the curator
- GTM Integration Specialist II links to the matching LinkedIn job because its direct employer URL could not be verified
- Search by job title or department
- No founders, revenue, company background or lengthy descriptions

## Preview locally

```sh
python3 -m http.server 5600
```

Open http://localhost:5600.

## Deploy

Import the repository in Vercel as a static Other-framework project. No install or build step.
